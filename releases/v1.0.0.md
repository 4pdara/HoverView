# HoverView 1.0.0

הגרסה הראשונה של HoverView — תמונות בגדול, במעבר עכבר.

## מה כלול?

- הגדלה ליד הסמן או במרכז המסך.
- ניסיון לטעון תמונה באיכות גבוהה יותר כשהאתר חושף מקור מתאים.
- זום בגלגלת, הצמדה ברווח, גרירה, סיבוב ופתיחה בלשונית חדשה.
- ממשק והוראות בעברית, מצב Alt והפעלה נפרדת לכל אתר.
- ללא חשבון, אנליטיקה או שרת עיבוד של התוסף.

## התקנה

1. הורידו **hoverview.zip** או **hoverview-v1.0.0.zip** וחלצו לתיקייה קבועה.
2. פתחו `chrome://extensions` והפעילו **מצב מפתח / Developer mode**.
3. לחצו **Load unpacked / טעינת תוסף לא ארוז** ובחרו את תיקיית **hoverview** שבתוכה `manifest.json`.
4. רעננו לשוניות שכבר היו פתוחות והעבירו את העכבר על תמונה.

זוהי התקנה מקומית. התוסף טרם פורסם בחנות Chrome. קובצי **Source code** ש־GitHub יוצר הם קוד המקור המלא; להתקנה הקלה בחרו בקובץ **hoverview.zip** המצורף.

התאימות משתנה בין אתרים. ראו README ו־VALIDATION.md לפרטים ולמגבלות האימות.

**SHA256SUMS.txt** מכיל חתימות SHA-256 לאימות תקינות קובצי ההורדה.
