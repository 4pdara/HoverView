# HoverView 1.0.1

תיקון איכות תמונות באליאקספרס והכנה לפרסום בחנות Chrome.

## תוקן

- בחירת מקור התמונה המלאה בשרתי התמונות של AliExpress, במקום הגדלת קובץ ממוזער כגון 220×220.
- תמיכה בסיומות שינוי גודל, איכות ופורמט WebP/AVIF בכתובות של alicdn.com ו־aliexpress-media.com.
- העדפת מקורות srcset גדולים על פני תמונות ממוזערות של טעינה עצלה.
- השארת המקור הזמין כחלופה אם התמונה הגדולה חסומה או אינה קיימת.

## איזה קובץ להוריד?

| קובץ | שימוש |
| --- | --- |
| **hoverview.zip** | התקנה ידנית במחשב דרך Load unpacked |
| **hoverview-webstore.zip** | העלאה ישירה ל־Chrome Web Store: manifest.json נמצא בשורש |
| **hoverview-store-kit-v1.0.1.zip** | כל חומרי ההגשה: ZIP להעלאה, צילומי מסך, אייקון, תמונות קידום, תיאורים והוראות מילוי |
| **SHA256SUMS.txt** | חתימות לאימות קובצי ההורדה |

## עדכון התקנה מקומית

חלצו את hoverview.zip והחליפו את הקבצים בתיקייה הקבועה של התוסף. פתחו `chrome://extensions`, לחצו על רענון בכרטיס HoverView, ואז רעננו את עמוד אליאקספרס.

עברו שוב עם העכבר על התמונה ובדקו את מידות המקור בתחתית החלונית. כשהמקור הגדול זמין הן אמורות להיות גדולות מ־220×220.

התיקון נבדק בבדיקות כתובות ובמקרי הצלחה/כישלון מבוקרים. גישה ישירה לעמוד המוצר הספציפי באליאקספרס נחסמה בסביבת הבדיקה; אימות באותו עמוד נותר לבדיקה אצל המשתמש.

התוסף **עדיין לא הוגש ולא פורסם בחנות Chrome**. ערכת ההגשה מכילה את החומרים הדרושים; אין להעלות את ZIP הערכה עצמה כחבילת התוסף. יש להעלות רק את ZIP ה־webstore שבתיקיית upload.
