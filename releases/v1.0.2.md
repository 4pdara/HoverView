# HoverView 1.0.2

תיקון תצוגות ריקות ותמונות שנעלמות כשהעכבר עדיין עליהן.

- התמונה מוצגת לאחר פענוח ומאותו רכיב שכבר נטען, בלי בקשת טעינה שנייה לתצוגה.
- מקור פגום או תמונה שקופה לחלוטין מפנים מקום למקור חלופי, ככל שהדפדפן מאפשר לבדוק אותו.
- גלילה של רכיב אחר בעמוד ושינויים לא קשורים אינם סוגרים את התצוגה כשהסמן עדיין מעל התמונה.
- מקורות שנטענים מאוחר ותמונות שמוחלפות בעמוד מתעדכנים גם בלי להזיז את העכבר.
- נשמר תיקון בחירת המקור באיכות גבוהה לאליאקספרס מהגרסה הקודמת.

| קובץ | שימוש |
| --- | --- |
| **hoverview.zip** / **hoverview-v1.0.2.zip** | התקנה ידנית: חילוץ וטעינת תיקיית hoverview במצב מפתח |
| **hoverview-webstore.zip** / **hoverview-webstore-v1.0.2.zip** | הקובץ להעלאה לחנות Chrome, עם manifest.json בשורש |
| **hoverview-store-kit-v1.0.2.zip** | ערכת הגשה מלאה: ZIP להעלאה, תמונות, תיאורים, פרטיות והוראות |
| **SHA256SUMS.txt** | אימות קבצים |

## עדכון התקנה קיימת

החליפו את הקבצים בתיקיית התוסף הקיימת בקבצי הגרסה החדשה, לחצו על רענון בכרטיס HoverView ב־chrome://extensions, ורעננו גם את לשוניות האתרים הפתוחות. שמירת אותה תיקייה שומרת על זהות ההתקנה וההגדרות.

## אימות

103 בדיקות במודל DOM ו־21 בדיקות בדפדפן Chrome עברו, כולל תצוגה יציבה מעבר ל־1.5 שניות, מקור שקוף/פגום, פענוח ותחלופת תמונות ללא תנועת עכבר. אלו מקרי בדיקה מבוקרים; ההתקנה כתוסף מלא והעמוד המסוים באליאקספרס עדיין דורשים בדיקה במחשב המשתמש. פרטים ב־extension/VALIDATION.md וב־store/COMPATIBILITY.md.

התוסף טרם הוגש לחנות Chrome. אתר: https://4pdara.github.io/HoverView/
