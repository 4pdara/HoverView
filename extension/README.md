# HoverView — הגדלת תמונות במעבר עכבר

תוסף Chrome עצמאי עם ממשק בעברית. מעבירים את העכבר על תמונה באתר ומקבלים חלונית גדולה ליד הסמן, ללא צורך לפתוח כל תמונה בנפרד.

## התקנה ב־Chrome

1. חלצו את קובץ ה־ZIP לתיקייה קבועה במחשב, למשל `Documents/hoverview`. אין למחוק את התיקייה אחרי ההתקנה.
2. כתבו בשורת הכתובת `chrome://extensions` והקישו Enter.
3. הפעילו **מצב מפתח / Developer mode** בפינה העליונה.
4. לחצו **טעינת תוסף לא ארוז / Load unpacked**.
5. בחרו את תיקיית **hoverview**, שבתוכה נמצא `manifest.json`.
6. פתחו את תפריט התוספים (סמל הפאזל) והצמידו את **HoverView** לסרגל הכלים.
7. **רעננו את האתרים שכבר היו פתוחים** לפני התקנת התוסף. עברו עם העכבר על תמונה והמתינו מעט.

התוסף אינו מפורסם בחנות Chrome. זוהי התקנה מקומית דרך מצב מפתח; לחיצה על ה־ZIP בלבד אינה מתקינה אותו.

## שימוש

| פעולה | איך עושים אותה |
| --- | --- |
| הצגת תמונה גדולה | מעבר עם העכבר מעל תמונה |
| הצמדה למסך | מקש רווח כשהתמונה מוצגת |
| סגירת תמונה מוצמדת | רווח פעם נוספת, Esc או כפתור הסגירה |
| זום | גלגלת מעל התמונה הקטנה; בהצמדה, בתוך החלונית |
| הגדלה / הקטנה במקלדת | `+` / `-` |
| הזזת תמונה אחרי זום | חצים, או גרירה בעכבר כשהחלונית מוצמדת |
| סיבוב ב־90 מעלות | `R`, בפריסת מקלדת אנגלית, או כפתור הסיבוב |
| איפוס זום וסיבוב | `0` |
| פתיחת מקור התמונה בלשונית חדשה | `O`, בפריסת מקלדת אנגלית, או כפתור פתיחה |
| הפעלה / השהיה כללית | `Alt+Shift+H` או חלון התוסף |

אפשר לשנות את הקיצור הכללי ב־`chrome://extensions/shortcuts` אם Chrome לא הקצה אותו, או אם הוא מתנגש בקיצור אחר.

קיצורי התמונה פעילים רק בזמן שתצוגת ההגדלה פתוחה, ואינם נתפסים בזמן הקלדה בשדות טקסט. גלגלת מעל תמונה פתוחה משמשת לזום; אפשר לבטל זאת בהגדרות כדי להחזיר גלילת עמוד רגילה.

## הגדרות

לחצו על סמל התוסף בסרגל הכלים. השינויים נשמרים אוטומטית ונכנסים לתוקף בלשוניות שכבר נטענו עם התוסף.

- הפעלה או השהיה בכל האתרים, וכיבוי נפרד לאתר הנוכחי.
- השהיה לפני הגדלה: 0–1,500 מילישניות. ברירת מחדל: 350.
- גודל מרבי: 40%–95% מהחלון. ברירת מחדל: 80%.
- תצוגה ליד העכבר או במרכז המסך.
- מראה כהה או בהיר, והצגת תיאור ומידות.
- מצב שבו הגדלה מתרחשת רק בזמן החזקת `Alt`.
- זום בגלגלת והגדלת תמונות רקע.
- **פתיחת דף הדגמה** עם שלוש תמונות מקומיות להתנסות.

הכיבוי לאתר חל על שם המארח המדויק: לדוגמה, `example.com` ו־`shop.example.com` נשמרים בנפרד. במסגרת משובצת מדומיין אחר ההגדרה נקבעת לפי הדומיין של אותה מסגרת. איפוס ההגדרות מחזיר את העדפות התצוגה לברירת המחדל ומשאיר בחירות הפעלה של אתרים כפי שהן.

אחוז הזום בחלונית מתייחס לגודל התמונה המותאם למסך. המידות המוצגות הן מידות קובץ המקור בפיקסלים. בתמונות SVG אלו המידות שהקובץ מצהיר עליהן.

## איכות התמונה

התוסף בודק קישורים לקבצי תמונה, מאפייני מקור כמו `data-original` ו־`data-full`, גרסאות `srcset` ו־`picture` ואת מקור התמונה המוצגת. יש גם ניסיונות להגעה למקור בחלק מכתובות התמונות של Wikimedia, Pinterest ו־X, עם חזרה לכתובת הזמינה במקרה של כישלון.

אין שרת עיבוד ואין שיפור תמונה באמצעות AI. אם האתר מספק רק תמונה קטנה, התוסף יכול להגדיל את התצוגה, אך אינו מסוגל להמציא פרטים שאינם במקור. מקור שדורש אימות מיוחד או חסום בידי האתר עשוי שלא להיטען; כל ניסיון מוגבל בזמן, והתוסף מנסה מקור חלופי כשיש כזה.

## פרטיות והרשאות

- כל הקוד כלול בחבילה. אין קוד מרוחק, אנליטיקה, שרת של התוסף או רישום היסטוריית גלישה.
- ההגדרות ושמות האתרים שהפעלתם או השבתתם נשמרים ב־`chrome.storage.local` במחשב ואינם מסונכרנים לחשבון.
- התוסף פועל בדפי `http` ו־`https` כדי לזהות את התמונות שמתחת לעכבר. לכן Chrome עשוי להציג הרשאה לקריאה ושינוי של נתוני אתרים; התוסף משתמש בגישה לקריאת מקורות תמונה ולהוספת חלונית התצוגה.
- `storage`: שמירת העדפות. `activeTab`: זיהוי שם האתר בעת פתיחת חלון התוסף.
- תמונות נטענות מהאתר או משרת התמונה המקורי באמצעות מנגנון התמונות הרגיל של הדפדפן. השרת עשוי לקבל בקשת טעינה, כתובת IP וכותרות שהדפדפן שולח כרגיל, וייתכן גם שימוש בעוגיות לפי מדיניות Chrome והאתר.
- פתיחת תמונה בלשונית יוצרת בקשה למקור התמונה. תמונות `data:` נשארות בחלונית בגלל מגבלות ניווט של הדפדפן.

ראו גם `PRIVACY.md`.

## תאימות ומגבלות

- Manifest V3; Chrome 109 ומעלה. מומלץ להשתמש בגרסה יציבה עדכנית. אפשר לנסות גם בדפדפני Chromium שתומכים בטעינת תוספים מקומיים.
- Chrome מונע פעילות של תוספים ב־`chrome://`, בחנות התוספים ובחלק מדפי הדפדפן הפנימיים. התוסף אינו מופעל על קובצי `file://` או בתוך מציג PDF המובנה.
- תמונות מצוירות ב־Canvas, נגן וידאו, תמונות ב־Shadow DOM סגור ומנגנוני גלריה ייחודיים עלולים לא להיות מזוהים. אין תמיכה ייעודית בכל האתרים ש־PhotoShow תומך בהם.
- תמונות במסגרת iframe מוצגות בתוך גבולות אותה מסגרת.
- אתרים עשויים לחסום טעינת מקורות חלופיים באמצעות מדיניות אבטחה, הגנת hotlink או קישורים חתומים.
- גודל תמונה קטן מ־24×24 פיקסלים בתצוגה לא מפעיל הגדלה, כדי לצמצם הפרעות מאייקונים. הגדלה חזותית רגילה מוגבלת לפי ארבעה ממידות המקור; זום ידני מאפשר להתקרב עוד.
- החבילה אינה כוללת עדכון אוטומטי. להתקנת גרסה חדשה מחליפים קבצים בתיקייה הקבועה, לוחצים על **רענון** בכרטיס התוסף ב־`chrome://extensions` ומרעננים את לשוניות האתרים.

## פתרון בעיות

**לא רואים הגדלה:** רעננו את עמוד האתר, בדקו שהמתג הכללי והמתג לאתר פעילים, ודאו שאינכם בעמוד פנימי של Chrome. אם מצב Alt פעיל, החזיקו Alt. אחרי Esc יש לצאת מגבולות התמונה ולחזור אליה כדי לפתוח אותה שוב.

**איכות התמונה נמוכה:** ייתכן שהאתר לא חשף גרסה באיכות גבוהה יותר.

**העמוד מפסיק לגלול כשמרחפים על תמונה:** כבו "זום באמצעות גלגלת העכבר" בחלון התוסף.

**אתר מסוים לא מתאים:** כבו את "הפעלה באתר הזה" בזמן שאתם נמצאים בו. אפשר גם לבחור הגדלה רק בזמן החזקת Alt.

## קוד ובדיקות

אין צורך ב־npm, שרת או תהליך build כדי להשתמש בתוסף. כל קובצי ההרחבה נמצאים בתיקיית `hoverview`.

החבילה כוללת קוד מקור פתוח ברישיון MIT. זהו מימוש עצמאי בהשראת אופן השימוש של PhotoShow; אין שיוך למפתחי PhotoShow ולא הועתק קוד שלהם.

פרטי האימות זמינים בקובץ `VALIDATION.md` שמצורף לחבילה.
