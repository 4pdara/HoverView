מדיניות פרטיות

עודכן: 2 בנובמבר 2026 · HoverView 1.0.1

מה התוסף עושה?

HoverView קורא מקורות של תמונות בדף האינטרנט ומציג תצוגה מוגדלת במעבר עכבר. העיבוד מתבצע בדפדפן; אין שרת עיבוד של התוסף.

לצורך הפעולה התוסף מטפל גם בתוכן תמונות ובכתובותיהן, בתיאורי תמונות ובשם המארח הנוכחי. העיבוד מקומי ואינו יוצר יומן ביקורים. בחירות הפעלה לפי אתר שומרות את שמות המארחים במחשב.

מה נשמר במחשב?

העדפות תצוגה ושמות המארחים שעבורם בחרתם להפעיל או לכבות את התוסף. הנתונים נשמרים ב־chrome.storage.local, אינם מסונכרנים בידי התוסף ונמחקים עם הסרתו.

מה נשלח החוצה?

התוסף אינו שולח נתוני גלישה, תמונות או מידע אישי לשרתי המפתח. אין אנליטיקה או טלמטריה. כדי להציג תמונה הדפדפן פונה לשרת התמונה המקורי, שעשוי לקבל כתובת IP, כותרות, מפנה ועוגיות לפי המדיניות הקיימת של הדפדפן והאתר.

למה נדרשות הרשאות?

גישה לדפי http ו־https מאפשרת לזהות את התמונה שמתחת לעכבר ולהוסיף חלונית תצוגה. storage משמשת לשמירת העדפות, ו־activeTab לזיהוי שם האתר בעת פתיחת חלון ההגדרות. התוסף אינו מקליט הקלדה; מאזיני המקלדת מפעילים קיצורי תצוגה בלבד.

ומה לגבי האתר הזה?

אתר התדמית מציג הדגמה מקומית באמצעות איורים המצורפים לפרויקט, ואינו כולל אנליטיקה, טופסי הרשמה או שירותי פרסום. ספק האחסון עשוי לעבד לוגים תפעוליים לפי מדיניותו. מעבר ל־GitHub כפוף למדיניות הפרטיות של GitHub.

השליטה אצלכם

אפשר לכבות את התוסף, להגביל גישה לאתרים דרך Chrome, לאפס העדפות או להסיר אותו. הקוד זמין בריפו הציבורי. לשאלות אפשר לפתוח Issue בלי לפרסם מידע אישי רגיש.

English privacy summary

HoverView processes image addresses, captions and image content locally to display larger previews. It reads the current hostname when opening its settings and stores per-host enable/disable preferences locally. It does not maintain a chronological browsing log, send data to a developer-operated server, use analytics or execute remote code.

Images are requested directly from their original hosts under normal browser policies; those requests may include IP addresses, referrers and cookies. The extension does not read cookie values. Preferences stay in chrome.storage.local and are removed when the extension is uninstalled. No user data is sold or used for advertising or lending decisions.

The static project website uses GitHub Pages; operational hosting logs are subject to the hosting provider's policies. Support is available through the public GitHub repository linked above.
