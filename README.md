# HoverView

**תמונות בגדול, במעבר עכבר.**

תוסף Chrome עם ממשק בעברית שמציג תמונות מוגדלות בתוך העמוד. HoverView מנסה לבחור מקור ברזולוציה גבוהה יותר כשהאתר חושף אותו, ומאפשר זום, הצמדה, גרירה וסיבוב בלי לאבד את המקום בגלישה.

**[אתר התדמית](https://4pdara.github.io/HoverView/)** · **[הורדת הגרסה האחרונה](https://github.com/4pdara/HoverView/releases/latest)** · **[דיווח על תקלה](https://github.com/4pdara/HoverView/issues)**

אתר התדמית מפורסם לציבור ב־GitHub Pages. קוד האתר המלא נמצא בתיקיית `website/`. התוסף טרם פורסם בחנות Chrome.

## התקנה

1. עברו ל־[Releases](https://github.com/4pdara/HoverView/releases/latest) והורידו את **hoverview.zip**. אל תבחרו ב־Source code לצורך ההתקנה הפשוטה.
2. חלצו את ה־ZIP לתיקייה קבועה. בתוכה תופיע תיקיית **hoverview**, ובה `manifest.json`.
3. כתבו בשורת הכתובת `chrome://extensions` והקישו Enter.
4. הפעילו **מצב מפתח / Developer mode**.
5. לחצו **טעינת תוסף לא ארוז / Load unpacked** ובחרו בתיקיית **hoverview**.
6. הצמידו את סמל התוסף דרך תפריט הפאזל ורעננו לשוניות של אתרים שכבר היו פתוחים.
7. העבירו את העכבר מעל תמונה. לפתיחת ההדגמה המצורפת, לחצו על סמל התוסף ואז על **פתיחת דף הדגמה**.

אין למחוק את תיקיית התוסף אחרי ההתקנה. להתקנה ישירות מקוד המקור, בחרו בתיקיית `extension/` אחרי הורדת הריפו.

## שימוש

| פעולה | קיצור |
| --- | --- |
| הצגת תמונה גדולה | מעבר עם העכבר |
| הצמדה / סגירת הצמדה | רווח |
| סגירה | Esc |
| זום | גלגלת מעל התמונה, או `+` ו־`-` |
| איפוס זום וסיבוב | `0` |
| סיבוב | `R` או כפתור הסיבוב |
| פתיחת מקור בלשונית | `O` או כפתור הפתיחה |
| הזזה אחרי זום | חצים, או גרירה כשהתמונה מוצמדת |
| הפעלה / השהיה כללית | `Alt+Shift+H` |

הקיצורים `R` ו־`O` משתמשים בפריסת מקלדת אנגלית. את הקיצור הכללי אפשר לשנות ב־`chrome://extensions/shortcuts`. קיצורי התמונה פעילים רק כשהחלונית מוצגת, ואינם נתפסים בזמן הקלדה בשדות טקסט.

## הגדרות

לחצו על סמל HoverView לשינוי ההגדרות. הן נשמרות אוטומטית ופועלות גם בלשוניות שכבר נטענו עם התוסף.

- הפעלה כללית והפעלה נפרדת לכל אתר.
- השהיה של 0–1,500 מילישניות וגודל מרבי של 40%–95% מהחלון.
- חלונית ליד העכבר או במרכז, מראה כהה או בהיר, תיאור ומידות.
- מצב Alt, זום בגלגלת וזיהוי תמונות רקע.

ברירת המחדל: התוסף פעיל, השהיה של 350 מילישניות, גודל מרבי 80% ומראה כהה. הפעלה לאתר נקבעת לפי שם מארח מדויק; מסגרת מדומיין אחר משתמשת בהגדרות של הדומיין שלה.

## איכות ותאימות

HoverView קורא קישורים לקובצי תמונה, מאפיינים כמו `data-original` ו־`data-full`, גרסאות `srcset` ו־`picture`, ואת מקור התמונה המוצגת. יש ניסיונות לקבל מקור בחלק מכתובות התמונות של AliExpress, X, Pinterest ו־Wikimedia, עם חזרה למקור זמין אם הניסיון נכשל.

אין שיפור תמונה באמצעות AI. כשאין מקור גדול יותר, הגדלת התצוגה אינה יוצרת פרטים חדשים. גלריות מיוחדות, Canvas, Shadow DOM סגור, כתובות מוגנות ומדיניות אבטחה של אתרים עשויים להגביל את פעולת התוסף. תצוגות בתוך iframe מוגבלות לגבולותיו.

Manifest V3, Chrome 109 ומעלה; מומלצת גרסה יציבה עדכנית. Chrome חוסם הרחבות בדפים פנימיים ובחנות התוספים. קובצי `file://` ומציג PDF המובנה אינם נתמכים. תמונות קטנות מ־24×24 פיקסלים אינן מפעילות הגדלה.

## פרטיות

אין חשבון, אנליטיקה, קוד מרוחק או שרת עיבוד של התוסף. רק הגדרות ושמות אתרים שהפעלתם או כיביתם נשמרים ב־`chrome.storage.local` במחשב.

הגישה לדפי http ו־https נחוצה לזיהוי התמונה ולהוספת חלונית. `storage` משמשת לשמירת העדפות ו־`activeTab` לזיהוי האתר כשהחלון נפתח. בקשות התמונה נשלחות לשרתי התמונה המקוריים ועשויות לכלול פרטי בקשת דפדפן רגילים לפי מדיניות Chrome והאתר.

ראו [מדיניות פרטיות](extension/PRIVACY.md).

## פיתוח ובדיקות

להרצת הבדיקות נדרשים Node.js 22 ומעלה ו־Python 3. אין צורך בהתקנת npm dependencies.

</div>

```bash
python3 scripts/package.py
npm test
```

<div dir="rtl">

הבנייה יוצרת בתיקיית `artifacts/` את `hoverview-v1.0.2.zip`, את `hoverview.zip` ואת `SHA256SUMS.txt`, ומעתיקה קובץ הורדה לאתר. ה־ZIP כולל את תיקיית `hoverview/`, ללא תיקיית הבדיקות. פרטי האימות ומגבלותיו נמצאים ב־[VALIDATION.md](extension/VALIDATION.md).

לתצוגה מקומית של האתר:

</div>

```bash
python3 -m http.server 8080 --directory website
```

<div dir="rtl">

לאחר מכן פתחו `http://localhost:8080`.

## הכנה לחנות Chrome

**[ערכת ההגשה המלאה לגרסה 1.0.2](https://github.com/4pdara/HoverView/releases/download/v1.0.2/hoverview-store-kit-v1.0.2.zip)** כוללת צילומי מסך, אייקון, תמונות קידום, תיאורים בעברית ובאנגלית, הוראות לבודק והסברי הרשאות ופרטיות.

להעלאה לחנות בחרו ב־**hoverview-webstore.zip**: בחבילה זו manifest.json נמצא בשורש. ה־ZIP הרגיל מיועד להתקנה ידנית וכולל תיקיית hoverview/. אין להעלות את ZIP ערכת ההגשה עצמה בתור התוסף.

ראו [הוראות ההגשה](store/UPLOAD-GUIDE.he.md), [דוח תאימות](store/COMPATIBILITY.md) ו־[הסברי הפרטיות](store/PRIVACY-AND-PERMISSIONS.md). התוסף טרם הוגש לחנות.

## פרסום האתר ב־GitHub Pages

תהליך **Deploy HoverView to GitHub Pages** בונה את קובץ ההורדה, מריץ בדיקות ומפרסם את תיקיית `website/` בכל שינוי רלוונטי שנדחף ל־`main`. אפשר להפעילו גם ידנית דרך Actions. מקור הפרסום בהגדרות Settings → Pages מוגדר ל־GitHub Actions.

## פרסום גרסה חדשה

1. עדכנו את `version` ב־`extension/manifest.json` וב־`package.json` לאותו מספר.
2. הוסיפו הערות גרסה ב־`releases/vX.Y.Z.md` ועדכנו את `CHANGELOG.md` ואת מספרי הגרסה המוצגים באתר ובתוסף.
3. הריצו בנייה ובדיקות, ואז העלו ל־`main`.
4. תהליך **Publish HoverView release** ב־GitHub Actions אורז את התוסף ומפרסם Release עם תגית הגרסה, חבילות התקנה ידנית, חבילות לחנות, ערכת הגשה וחתימות SHA-256.

התהליך אינו משנה Release שכבר קיים עם אותו מספר. אפשר להפעילו ידנית דרך Actions → Publish HoverView release → Run workflow. אם GitHub דורש אישור להפעלת Actions בריפו, יש לאפשר אותו בהגדרות הריפו. פרסום דורש הרשאת `contents: write` שהוגדרה בתהליך.

התוסף המותקן מקומית אינו מתעדכן אוטומטית. לעדכון מחליפים את הקבצים בתיקייה הקבועה, מרעננים את כרטיס התוסף ב־`chrome://extensions` ומרעננים את לשוניות האתרים.
